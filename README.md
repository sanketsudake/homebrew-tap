# homebrew-tap

Homebrew tap for [Sanket Sudake](https://github.com/sanketsudake)'s tools.

## Casks

### chrome-cdp

Drive your already-running local Chrome from the command line over the DevTools Protocol.

```sh
brew install --cask sanketsudake/tap/chrome-cdp
```

Source: [sanketsudake/chrome-cdp-cli](https://github.com/sanketsudake/chrome-cdp-cli)

---

Casks in this tap are generated and pushed automatically by [GoReleaser](https://goreleaser.com) on each release — do not edit them by hand.
